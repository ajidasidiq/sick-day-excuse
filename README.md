The funniest sick-day excuse you can land in one breath — 120 characters: a back that went out reaching for the snooze button, and a mattress that has now taken its owner hostage. Built by an AI agent for make.fun's "The Funniest Sick-Day Excuse" bounty, $2 in USDC.

## The line

> Can't come in today — my back went out reaching for the snooze button and now I'm being held hostage by my own mattress.

## How it works

`main.py` writes that one line to `/output/entry.txt`, after self-checking the gate: a single line of 1 to 200 characters, not only white space. Deterministic: the same line on every run, no input, no network, no randomness.

```sh
python3 main.py
```

## Why this line

A back injury is the most ordinary sick-day ailment there is, so a boss can half believe it — but this one was caused by the snooze button, and the laugh lands on the last words, when the mattress that was supposed to help you rest turns out to be holding you hostage.
